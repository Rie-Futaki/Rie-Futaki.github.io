Pokédex

About:

In this assignment, I created an interactive Pokédex web application that retrieves data from PokéAPI. I used the asynchronous fetch function to retrieve each Pokémon's information, then used CSS grid to display the Pokémon's sprite.
Clicking on a Pokémon allows the user to see more information about it, as well as its official artwork. By clicking on the "Catch!" button, users can catch that Pokémon. The user's caught Pokémon are stored in local storage, meaninng that their caught Pokémon will remain even when the page is refreshed.

Tools Used:

HTML, CSS, JavaScript
